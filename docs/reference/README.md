# Setun-70 sources

The historical Setun-70 is background for this project, not part of it
([`ARCHITECTURE.md`](../ARCHITECTURE.md) is a digest). Its sources are not kept
here: they belong to their authors and publishers. Stanislav Maslovski's
Setun-70 emulator collects them, with the report's ALGOL text transcribed:
<https://github.com/smaslovski/Setun70>.

- N. P. Brusentsov, E. A. Zhogolev, *Algorithmic description of the structure
  and instruction set of the Setun-70 computer* (Алгоритмическое описание
  структуры и системы команд ЭВМ «Сетунь-70»), MSU Computing Center
  scientific report No. 27-VT (417), Moscow, 1970. The primary source. Its
  ALGOL text, OCR'd and edited by S. Maslovski: [`Setun70.alg`](https://github.com/smaslovski/Setun70/blob/master/Setun70.alg);
  the start-up ROM: [`ROM.csv`](https://github.com/smaslovski/Setun70/blob/master/ROM.csv); the scan: [`docs/`](https://github.com/smaslovski/Setun70/tree/master/docs).
- N. P. Brusentsov, E. A. Zhogolev, V. P. Maslov, *General characteristics of
  the Setun-70 computer* (Общая характеристика ЭВМ «Сетунь-70»), 1971. The
  overview paper (Russian).
- *Setun-70 instruction set description* (Описание набора инструкций «Сетунь-70»)
  and the *Setun-70 symbol set*: summaries of the instruction set and the
  character code (Russian).
- *Consul 254 technical description*: the teleprinter the Setun-70 used.
- N. P. Brusentsov, J. Ramil Alvarez, "Ternary Computers: The Setun and the
  Setun 70", in J. Impagliazzo, E. Proydakov (eds.), *Perspectives on Soviet
  and Russian Computing* (SoRuCom 2006), IFIP Advances in Information and
  Communication Technology 357, Springer, 2011, pp. 74–80,
  [doi:10.1007/978-3-642-22816-2_10](https://doi.org/10.1007/978-3-642-22816-2_10).
