Log in as user (password user) or root (password root). Click the screen to type, or use the serial console. Try ls /bin, ps, uname -a, calc, the crypto self-test cryptotest, ssh-keygen -f key or x509 -l (the TLS roots), or Window system for trwm term clock colors paint: drag windows by their title bars, type in the terminal, close with the red box, leave with Exit. Power-cycle keeps the disk; Fresh disk restores it. Screen sets the picture's size on the page, and Window system then runs at that size (trwm -g 1024x768); Full screen fills the display (hold Esc to leave). Alt+Shift switches the keyboard between English and Russian. Network → Internet power-cycles the machine with its network card linked, through the server, to the internet (not to the server's own network): then try host example.com, wget -O - https://example.com or ssh to a machine you have an account on.

Type on the screen or in the serial console. Tab shows the 3^9-colour sweep; any key returns.
